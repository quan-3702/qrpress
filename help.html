How to use QRPress

1. Choose the kind of code

QR code for links, text, Wi-Fi, a contact card, an email or a text message. Code 128 for stock numbers, asset tags, tickets and anything with letters and numbers. EAN-13 and UPC-A (Pro) for product barcodes – type 12 or 13 numbers (UPC-A: 11 or 12), QRPress adds or checks the last number for you.

2. Type your codes

One code per line. To show other text under the code, write code | text, for example https://mysite.com/menu | Our menu. From a CSV / TXT file reads a list from Excel (save it as CSV): the first column is the code, the second the text under it. Numbers in a row makes INV-0001 to INV-0500 in one click.

3. Wi-Fi sign for guests

Choose QR code → Wi-Fi, type the network name and password, and print with One big code per page. Guests point the phone camera at it and join – no typing.

4. Print on labels

Choose your label sheet (Avery 5160, 5163, 5167, A4 L7160, L7159, L7651), plain paper with cut lines, one big code per page, or Label printer with your label size. Copies of each code fills the sheet with the same code. Skip used labels starts after the labels you already used on a sheet. In the print window choose Scale: 100% (or “Actual size”) and Margins: None, so the codes land exactly on the labels.

5. Pictures

Save picture saves the first code as a PNG. With Pro, ☰ More → Save all codes as pictures saves every code into one ZIP file, and SVG is there for designers.

Free and Pro

Free: QR codes and Code 128, up to 10 different codes at a time, all label sheets, a small “Made with QRPress” line on the page. Pro (one-time purchase, no subscription): unlimited codes, EAN-13 and UPC-A, your logo in the QR code, your colour, all codes as pictures (ZIP) and SVG, no line on the page.

Tip

Always test a code with your phone before printing hundreds. Very small codes, light colours and big logos are harder to scan.
